## Where things go

- New rule or number: `src/game/` (pure; add content to `src/game/content/`).
- New screen or UI piece for one feature: `src/features/<feature>/`.
- UI used by several features: `src/components/`; stock shadcn primitives: `src/components/ui/`.
- Anything that touches the DOM, audio or `localStorage`: a feature folder, never `src/game/`.
- Scripts run outside the browser: `tools/`.
